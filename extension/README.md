# 起点 · 离线新标签页

适用于桌面 Chrome、Microsoft Edge 等支持 Manifest V3 的 Chromium 浏览器。

## 安装

1. 将 `qidian-newtab-1.0.0.zip` 解压到一个准备长期保留的文件夹。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的 `qidian-newtab` 文件夹。若解压工具没有创建外层文件夹，直接选择包含该文件的解压目录。
5. 新建普通标签页；浏览器首次询问是否保留新标签页更改时，选择保留。

ZIP 用于解压安装，未发布到扩展商店；直接拖入 ZIP 不是安装方式。浏览器的无痕新标签页不支持此替换。

## 本地优先与回退

每次新建标签页直接加载扩展内的 HTML、脚本、样式及品牌图标，不需要启动本机服务，断网也可使用页面和本机设置。正常启动不探测备用服务器。

核心脚本或样式加载失败、页面初始化抛出错误，或 8 秒内仍未完成初始化时，当前标签页会跳转到 `https://www.nyqking.top/`。单个网站图标加载失败不会触发跳转。扩展被禁用或入口文件本身损坏时，浏览器无法执行回退逻辑，需要重新加载完整的扩展文件。

扩展不申请浏览历史、标签页、书签或网站访问权限，不加载远程脚本。访问搜索结果、网站链接以及在线回退页仍需要相应网站可访问。

## 设置与更新

网站、搜索引擎、主题、紧凑模式、背景图片、导入导出及搜索快捷键均保留。「使用扩展默认配置」用于恢复扩展附带的 `config.js`，仍需点击「保存设置」才生效。

设置保存在当前浏览器的扩展存储空间，与在线网站的设置相互独立。如需沿用在线页的设置，请先在在线页导出 `config.js`，再在扩展的「管理设置 → 导入配置」中导入并保存。回退到在线页时使用在线页自己的设置。

更新时先导出设置备份，用新版文件覆盖原安装文件夹，再在扩展管理页点击「重新加载」。扩展的公开标识密钥保持不变；不要卸载扩展后再安装，卸载可能清除本机设置。

## 源码与许可

包内 HTML、JavaScript、CSS 和图标均为可直接阅读的相应源码，没有压缩或隐藏代码，同时包含原始入口、扩展源文件与 `scripts/package-extension.py`，可重新打包。完整项目与回归检查见 https://github.com/NielaoGanBu/personal-navpage-qidian 。保留包内的 LICENSE、LICENSES、THIRD_PARTY_NOTICES.md 及 icons/sources.json；整合版本的分发条款见第三方说明。
